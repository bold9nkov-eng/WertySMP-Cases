WertySMP-Cases 1.2.0 — исходный проект для Paper 1.21.11

ВАЖНО: это ИСХОДНЫЙ КОД, не готовый JAR. Для установки нужно собрать проект Maven с Java 21 и доступом к Paper API 1.21.11.

Крафты: плагин не добавляет и не регистрирует рецепты. Все рецепты кейсов ты настраиваешь самостоятельно.

Внешний вид: обычный кейс использует обычный сундук, эпический — сундук-ловушку, легендарный — эндер-сундук. Это разные стандартные варианты Minecraft. Для уникальных авторских моделей/текстур понадобится отдельный ресурс-пак.

Команды (только игроки онлайн):
/wcases give <игрок> ordinary [количество]
/wcases give <игрок> epic [количество]
/wcases give <игрок> legendary [количество]
Также принимаются типы: обычный, эпический, легендарный.
Примеры:
/wcases give NeZoX_123 ordinary 5
/wcases give NeZoX_123 epic 1
/кейсы give NeZoX_123 legendary 1

Право: wertysmpcases.admin (по умолчанию у OP).

Механика:
- Предмет кейса — сундук с внутренней PDC-меткой; обычные сундуки не затрагиваются.
- ПКМ по поставленному кейсу открывает его, выдаёт все награды, прошедшие независимую проверку шанса, и удаляет блок.
- Если инвентарь заполнен, остаток падает рядом с игроком.
- Каждый шанс — отдельный процентный бросок. Награды с шансом 100% выдаются при каждом открытии.
- Количество каждой награды случайно в диапазоне min-max включительно.
- Броня — случайная часть соответствующего комплекта; стрелы имеют эффект плавного падения; ракеты имеют длительность полёта III.

Ограничения:
- Булава выдаётся как стандартный предмет MACE Minecraft. Особая модель/характеристики из другого плагина автоматически не переносятся.
- Плагин не требует Vault, потому что текущий список наград не содержит денег.
- Перед заменой/установкой сделай резервную копию сервера и сначала проверь на тестовом сервере.
- Сборка: Java 21 + Maven; команда `mvn package`; итоговый JAR будет в target/.
