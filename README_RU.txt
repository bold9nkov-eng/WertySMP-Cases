# Void-cases-v2 3.0.0

Плагин для Paper 1.21.11 и Java 21. Переименован из WertySMP-Cases, сохраняет текущие встроенные кейсы и переносит старые настройки.

## Команды
- `/case` — открыть панель управления (администратор).
- `/case create` — открыть панель создания нового кейса.
- `/case editor` — список кейсов и настройки.
- `/case give <игрок> <тип> [количество]` — выдать кейс.
- `/case preview <тип>` — посмотреть добычу и шансы.
- `/case daily` — ежедневные награды.
- `/case top` — статистика открытий.
- `/case reload` — перечитать config.yml.

## Редактор кейсов
1. Открой `/case create`, нажми «Создать кейс» и введи имя в чат.
2. В настройках можно переименовать кейс, открыть список лута и посмотреть предпросмотр.
3. Чтобы задать модель блока, возьми в основную руку сундук, сундук-ловушку, эндер-сундук, бочку или шалкеровый ящик и нажми «Выбрать модель из руки». Сохраняются метаданные предмета; для собственного внешнего вида блока нужен соответствующий ресурс-пак.
4. В редакторе лута перетащи предмет из своего инвентаря в свободную ячейку верхней панели. Все метаданные предмета сохраняются. По умолчанию шанс 100%, количество — размер добавленной стопки.
5. Нажми на награду, чтобы изменить шанс (0–100%), минимальное/максимальное количество, название или удалить её.

Награды обычных, эпических, легендарных и пользовательских кейсов проверяются независимо по шансам. Для встроенного кейса Пустоты сохраняется его взвешенная система выпадения.

## Совместимость и данные
- Перед заменой останови сервер и сделай резервную копию папки `plugins/WertySMP-Cases`.
- Удали старый JAR WertySMP-Cases, затем помести `Void-cases-v2-3.0.0.jar` в папку `plugins`.
- При первом запуске плагин автоматически копирует `config.yml` и `data.yml` из `plugins/WertySMP-Cases` в новую папку `plugins/Void-cases-v2`, если в новой папке таких файлов ещё нет.
- Старое разрешение `wertysmpcases.admin` поддерживается. Новое разрешение: `voidcases.admin` (по умолчанию OP).
- Старые команды `/wcases`, `/wcaces`, `/wcasec` и `/wcacec` не регистрируются. Основная команда теперь `/case`.

## Сборка
Java 21 + Maven: `mvn --batch-mode clean package`. Результат: `target/void-cases-v2-3.0.0.jar`.
